Novel Reader — Android project (v2.0)
====================================

هذا هو المشروع المصدري لتطبيق Novel Reader، وليس APK جاهزًا. تم تجهيز الواجهة ونظام المكتبة والوظائف الأساسية في هذه النسخة، لكن يلزم بناء APK وتجربته على جهاز Android قبل اعتبار الإصدار نهائيًا.

الوظائف الموجودة في المشروع:
- مكتبة متعددة الروايات مع استيراد EPUB، كشف التكرار ببصمة SHA-256، واستخراج غلاف EPUB إن توفر.
- متابعة القراءة وترتيب المكتبة حسب آخر إضافة أو آخر قراءة أو الاسم أو عدد الفصول، مع عرض شبكي/قائمة.
- فتح الرواية من آخر موضع محفوظ، وفهرس قابل للبحث وتحديد عدة فصول يدويًا.
- قارئ عربي افتراضيًا، مع عرض الأصل عند الطلب، وتمرير مستمر، وأزرار السابق/التالي وإيماءة السحب.
- وضع قراءة غامر: لمسة قصيرة على مساحة القراءة لإظهار/إخفاء عناصر الواجهة، مع تمييزها عن التمرير.
- ترجمة MyMemory ثم Google Translate، وحفظ الفقرات تدريجيًا، واستكمال الجزئي.
- ترجمة جماعية حتى 50 فصلًا بالتتابع، وتسجيل نجاح/فشل المحاولات وسجل دائم لكل رواية.
- تصدير EPUB كامل: يستبدل الفقرات المترجمة ويُبقي غير المترجم أصليًا. وتصدير TXT كامل بنفس القاعدة.
- نسخ احتياطي للمكتبة أو لرواية واحدة بصيغة JSON غير مضغوطة، واستعادة تضيف الروايات غير الموجودة فقط.
- مظهر داكن/فاتح/حسب الجهاز، إعداد حجم الخط وتباعده، وقراءة مساحة التخزين التقريبية.
- اسم التطبيق والأيقونة باسم Novel Reader.

ملاحظات واختبارات:
- تم فحص صياغة JavaScript باستخدام node --check وفحص سلامة ملف ZIP.
- لم يتم بناء APK في بيئة العمل هذه لعدم توفر Gradle/Android SDK هنا. استخدم GitHub Actions المرفق لبناء APK.
- يلزم اختبار استيراد EPUBs مختلفة، الترجمة الجماعية، النسخ الاحتياطي والاستعادة والتصدير على هاتف فعلي.
- استمرار الترجمة أثناء التنقل داخل التطبيق مدعوم ما دامت الرواية نفسها مفتوحة؛ التبديل إلى رواية أخرى أثناء وجود ترجمة نشطة محجوب مؤقتًا لحماية حالة الترجمة الحالية. استمرار العمل بعد إغلاق التطبيق بالكامل غير مضمون.
- خيار English في هذه النسخة يبدّل اتجاه/لغة المستند وبعض عناوين المكتبة، وليس ترجمة كاملة لكل النصوص والرسائل بعد.
- خدمات الترجمة تحتاج الإنترنت وقد تفرض حدود استخدام أو تتوقف مؤقتًا.

بناء APK عبر GitHub:
1. ارفع محتويات هذا المشروع إلى مستودع GitHub.
2. افتح Actions ثم Build Android APK وشغّل workflow.
3. نزّل artifact باسم NovelReader-debug-apk عند نجاح البناء.
